# Miyori Code

AI-native portfolio landing: Next.js 14 App Router, next-intl (EN/RU), marble + WebGL fluid cursor.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- next-intl (EN / RU)

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Drop your memoji at `public/avatar.png` (about 280×280). Until then the page falls back to `public/avatar.svg`.
